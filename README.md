# UoB Calendar Export

A Firefox extension for exporting calendars from the University of Bristol app as `.ics` files.

## Features

- Export up to 24 months of events
- Choose which calendars to include
- Combine everything into one file or create separate files
- Import the results into Google Calendar, Outlook, Apple Calendar, and other calendar apps

## Usage

1. Install the extension in Firefox.
2. Open [app.bristol.ac.uk](https://app.bristol.ac.uk/campusm/home#calendars) and sign in.
3. Click the extension icon.
4. Choose a date range and the calendars to include.
5. Click **Export .ics**.

## Privacy

Calendar data is retrieved directly from the University of Bristol portal, processed locally in Firefox, and saved to your computer. The extension contains no analytics and sends no data to the developer or other third parties.

Exported files may contain private information, including locations, staff names, course details, notes, and online-meeting links. Store and share them carefully.
